# Кассовые смены

Для маршрутов кассы необходимы claims sub, branch_id и scope qsr.pos.
Одна касса филиала может иметь одну открытую смену. Ограничение закреплено уникальным индексом PostgreSQL.

POST /api/cash-shifts
Тело содержит registerCode, currency и openingAmount.

GET /api/cash-shifts/{id}
Возвращает открытие, ожидаемый остаток, движения, закрытие, фактический остаток и расхождение.

POST /api/cash-shifts/{id}/entries
Тело содержит key (UUID), type (1 для внесения, 2 для изъятия), amount и reason.
Повтор key с теми же данными не меняет баланс. Изменение данных с тем же key возвращает 409.

POST /api/cash-shifts/{id}/close
Тело содержит countedAmount. Закрытая смена запрещает новые движения.

POST /api/orders/{id}/payments/cash
Тело теперь содержит amount и shiftId. Заголовок Idempotency-Key обязателен.
Платёж и движение продажи сохраняются в общей сериализуемой транзакции.
Конфликт конкурентной записи требует повторного чтения состояния перед повтором с тем же ключом.

Возвраты наличных ещё не подключены к кассовой книге через API. Фискальные отчёты и подтверждение провайдера требуют выбранного оборудования.
Новые таблицы добавляются миграцией CashShifts.
